# #22 获取并校验可复用的只读 Arch 基础镜像

[GitHub Issue #22](https://github.com/xingjianxu/dek/issues/22) · Task

- 分支：`issue-22-arch-vm-image`
- Worktree：`/data/dek-dev/worktrees/22-arch-vm-image/`

## 交付目标

为每轮虚拟机测试提供可核验、可复用的版本化基础镜像。

## 范围与接口

在 scripts/ 提供 Arch 官方 x86_64 cloudimg 镜像准备入口；下载缓存与基盘保存在 /data/dek-dev/。

设计位置：[docs/design.md](../design.md) §10.7–10.8。

直接前置：[#1](1.md)。

## 实施步骤

1. 按官方发布信息选定镜像版本及可信签名校验材料，下载到临时文件。
2. 验证签名和内容摘要，成功后发布到 vm/base/<image-id>/，保留旧版本供活动轮次引用。
3. 记录版本、验证依据与摘要，供启动脚本核对基盘。

## 验收条件

- [ ] 篡改签名或下载内容后运行入口，命令失败且已验证的镜像仍可用。
- [ ] 重复准备同一版本复用只读基盘；准备另一版本后两个版本均可按标识取用。

提交与 PR 验证按[协作约定](../../AGENTS.md)执行。
