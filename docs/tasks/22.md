# #22 获取并校验可复用的只读 Arch 基础镜像

[GitHub Issue #22](https://github.com/xingjianxu/dek/issues/22) · Task

- 分支：`issue-22-arch-vm-image`
- Worktree：`/data/dek-dev/worktrees/22-arch-vm-image/`

## 交付目标

为每轮虚拟机测试提供可核验、可复用的版本化基础镜像。

## 范围与接口

在 scripts/ 提供 Arch 官方 x86_64 cloudimg 镜像准备入口；下载缓存与基盘保存在 /data/dek-dev/。

设计位置：[docs/design.md](../design.md) §10.7–10.8。

直接前置：[#1](1.md)。

## 实施步骤

1. 按官方发布信息选定镜像版本及可信签名校验材料，下载到临时文件。
2. 验证签名和内容摘要，成功后发布到 vm/base/<image-id>/，保留旧版本供活动轮次引用。
3. 记录版本、验证依据与摘要，供启动脚本核对基盘。

## 使用

`scripts/arch-vm-image prepare <image-id>` 使用 Arch 官方镜像索引中的版本目录名，例如 `v20261115.625457`。`scripts/arch-vm-image check <image-id>` 复核已发布版本，两条命令均在标准输出写出验证通过的基盘路径。可以用 `prepare --source-dir <目录> <image-id>` 验证离线取得的同名镜像及其三个验证文件。

数据根由 `DEK_DEV_ROOT` 指定，默认是 `/data/dek-dev`。验证临时文件和锁放在 `cache/arch-vm/`，成功后的 `vm/base/<image-id>/` 包含只读的 `image.qcow2`、`metadata.json` 和上游验证文件。运行入口使用 Bash、curl、GnuPG 的 `gpg` 和 `gpgv`、jq、flock 以及常见的 Linux 基础工具。

版本和文件名见 [Arch 官方镜像索引](https://geo.mirror.pkgbuild.com/images/)。公钥取自 [arch-boxes 官方 README](https://github.com/archlinux/arch-boxes/blob/7f733af26fe9a0c93fdabba13e7803cbe803374a/README.md#releases)，验证与发布约定见 [ADR](../adr/22-arch-vm-image-trust.md)。

## 验收条件

- [x] 篡改签名或下载内容后运行入口，命令失败且已验证的镜像仍可用。
- [x] 重复准备同一版本复用只读基盘；准备另一版本后两个版本均可按标识取用。

在 wks-lab 用 `v20261115.625457` 和 `v20261101.620452` 的官方文件运行 `scripts/tests/arch-vm-image <上游文件父目录> v20261115.625457 v20261101.620452`，覆盖两种签名与镜像内容损坏、离线复用及多版本共存。测试所需的上游文件按版本分目录，保留发布时的文件名。

提交与 PR 验证按[协作约定](../../AGENTS.md)执行。
