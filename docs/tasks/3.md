## 交付目标

让规划器和执行器共享同一份类型化资源和审阅计划。

## 范围与接口

在 `crates/dek-core` 增加资源身份、目标能力、动作及前置条件。复用声明模型的来源定义。

设计位置：[docs/design.md](../design.md) §1.1、§2.2、§3、§4.3、§9。

直接前置：[#2](2.md)。

## 实施步骤

1. 建模包来源、目标路径、账户和含作用域的 unit 身份；保留依赖、通知与内容引用。
2. 定义 Plan 版本、目标和仓库绑定、所用能力、资源摘要、带原因与前置条件的有序动作。
3. 加入可由后续目标端读写的样本，覆盖不兼容版本和未知动作。

## 验收条件

- [ ] 往返系统级、Alice 和 Bob 的 backup.timer，标识互异，enabled 和 running 可独立省略。
- [ ] 往返含文件内容摘要的计划，动作顺序、来源、绑定及前置条件相同。未知动作和不兼容格式返回可定位错误。
