# #23 从只读基盘按轮启动、重启与收尾 Arch 测试虚拟机

[GitHub Issue #23](https://github.com/xingjianxu/dek/issues/23) · Task

- 分支：`issue-23-arch-vm-harness`
- Worktree：`/data/dek-dev/worktrees/23-arch-vm-harness/`

## 交付目标

让开发机从已验证的只读 Arch cloudimg 启动可独立重启、部署和收尾的 QEMU/KVM 测试目标。

## 范围与接口

在 `scripts/` 增加镜像与集成环境入口，定义 cloud-init 模板、测试专用 SSH 身份和证据目录。镜像、差分盘、密钥及日志均放在 `/data/dek-dev/`。包/AUR 测试联网方式留给对应策略决定。

设计位置：[docs/design.md](../design.md) §9.1、§10.6、§10.7、§10.8、§11。

直接前置：[#22](22.md)。

## 实施步骤

1. 检查 x86_64 Linux、QEMU/KVM 工具及 /dev/kvm 访问，按镜像标识选择已验证的只读基盘。
2. 在 `runs/<issue>/<run>/` 生成 qcow2 差分盘、cloud-init 和串口日志，分配独立实例标识及绑定 `127.0.0.1` 的 SSH 端口。默认 2 vCPU、2 GiB，允许 AUR 场景调高。
3. 等待 cloud-init 完成和 SSH 可用后部署本轮已构建的 `dek`，支持同一轮重启保留磁盘。记录镜像、构建版本、端口、实例、命令与日志的位置。 在 Arch 来宾实际运行 dek --version，验证构建产物的动态加载器及运行库兼容。
4. 按本轮归属关闭实例。成功可清理差分盘，失败保留盘与日志供复查，应对启动失败、中途退出和同时运行多个实例。

## 使用

在 wks-lab 上使用 QEMU/KVM、UEFI 固件、OpenSSH、Python 3、jq、dosfstools 和 mtools。用 [#22 的镜像入口](22.md)准备基盘，再交给测试脚本。默认资源为 2 vCPU、2048 MiB，分别用 `DEK_VM_CPUS` 和 `DEK_VM_MEMORY_MIB` 覆盖。脚本在 QEMU 自带固件目录中查找 UEFI，也可用 `DEK_VM_FIRMWARE_CODE` 和 `DEK_VM_FIRMWARE_VARS` 指定文件。

```bash
export CARGO_HOME=/data/dek-dev/cache/cargo
export CARGO_TARGET_DIR=/data/dek-dev/cargo/target/23-arch-vm-harness
NIX_DONT_SET_RPATH_x86_64_unknown_linux_gnu=1 \
  cargo rustc --locked -p dek-cli --bin dek --target x86_64-unknown-linux-gnu -- \
  -C link-arg=-Wl,--dynamic-linker=/lib64/ld-linux-x86-64.so.2
binary="$CARGO_TARGET_DIR/x86_64-unknown-linux-gnu/debug/dek"
scripts/arch-vm-image prepare v20261115.625457
run=$(scripts/run-arch-vm start 23 v20261115.625457 "$binary")
scripts/run-arch-vm ssh "$run" /usr/local/bin/dek --version
scripts/run-arch-vm reboot "$run"
scripts/run-arch-vm finish "$run" passed
```

`start` 输出本轮目录。这里的 SSH 密钥、差分盘和日志均按轮隔离。网络仅允许回环转发到来宾 SSH，登陆时使用本轮预置的来宾主机公钥。`config` 返回可用于 `ssh -F <配置> dek-vm` 的文件路径。`finish passed` 关闭来宾并清理差分盘，`finish failed` 或 `finish keep` 保留差分盘和日志。带编号的其他集成任务可以使用自己的 Issue 号创建轮次。

完整双机验收使用 iproute2 的 `ss`。命令为 `scripts/tests/arch-vm v20261115.625457 "$binary"`。证据包含来宾实例、启动命令、二进制摘要及版本、SSH 端口、来宾串口和 cloud-init 状态。
