## 交付目标

在主仓库归档 `docs/wiki/`，使使用文档能随功能变更一起评审并随版本检出。GitHub Wiki 从主仓库手动同步。

## 实施步骤

1. 将现有 Wiki 页面、侧栏、页脚与发布说明保存到 `docs/wiki/`。
2. 更新 `docs/wiki/README.md`，记录在主仓库评审文档以及从合入版本单向发布到 Wiki 的操作。
3. 核对发布内容和链接，运行 `./scripts/check` 并查看 GitHub Actions 结果。

## 验收条件

- 从 PR 检出时，`git ls-files docs/wiki/` 列出 17 个 Markdown 文件。对照 Wiki 当前版本，16 个发布文件逐字节一致，页面间的相对链接均有目标。
- 从相同源码重复准备发布时，Wiki 工作副本的暂存差异为空，说明要求跳过提交和推送。改变一个页面后重新准备发布时，暂存差异仅包含该页面。
- `./scripts/check` 与 GitHub Actions 均通过。
