# #7 在资源组装时读取待部署文件

状态为已采纳，关联 [#7](../tasks/7.md)。

[设计 §3 与 §4.2](../design.md) 区分模块读取的选项与部署内容。让模块展开器读取文件并返回最终摘要，会使文件内容变化也触发模块重算。把文件路径交给目标会要求目标取得管理机仓库。

注册表以开关决定是否调用模块。模块只读取其登记的选项路径或子树，展开结果保留源文件的位置与声明出处，以及生成的内联内容。未提供精确范围时记录完整生效选项。管理机在组装时读取相对于声明文件的路径，按字节计算 SHA-256，输出目标路径、内容摘要和可传输字节。目标路径保留原始拼写，目标端负责判断路径别名的同一性。

同一身份的相同资源合并来源、依赖和通知。不同期望状态冲突时同时显示双方来源。资源依赖与服务通知作为独立关系保存，依赖缺失和循环在组装时报告。
