# #15 从共享的生效配置展示选项来源

状态为已采纳。

## 背景

`show` 需要展示主机的生效选项。`plan` 需要用相同配置继续展开模块，增量采集也需要复用该路径。参见 [#15](../tasks/15.md)、[#16](../tasks/16.md) 和 [#18](../tasks/18.md)。

## 决定与影响

管理端通过同一个入口加载 schema、使用传入的采集器展开声明图并合并出 `HostConfig`。结果保留仓库模块注册，调用方可以沿用采集时的 Ruby 会话和输入提供者继续展开。

文本和 JSON 均读取 `HostConfig`。命令筛选选项时继续使用以完整路径为键的 `options` 对象，保留既有优先级、生效定义和覆盖定义的表示。采用统一结构可以用同一脚本读取整机与单项结果。参与查询的目标快照通过单独的 `targetSnapshot.label` 标记。
