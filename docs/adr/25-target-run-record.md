# #25 将执行回执保存在目标状态目录

状态为已采纳。关联 [任务 #25](../tasks/25.md) 与[设计 §4.3](../design.md)。

## 背景

执行器可能在调用后端和记录回执之间退出。之后的进程需要按目标、仓库和执行请求找到原运行，复核结果仍不明确的动作。正在执行或待恢复的运行需要保留其计划及内容。

## 决定与影响

在同一目标状态锁中把版本化 MessagePack 运行记录发布到 `runs/<run-id>.mpk`。运行 ID 绑定请求标识、仓库、逻辑主机及目标身份。重发同一请求返回原记录，重复使用该标识绑定其他计划会报错。同一绑定内的创建序号决定最新运行。

在调用后端前持久化动作的尝试号及结果待核验状态。如果已有一次结果不明的尝试，返回待核验状态与原尝试号。回执携带尝试号，重复提交同一回执无需重写。序号匹配后才原子替换记录。文件变更前可登记计划中的通知，服务动作核验成功时与回执一并清除待办。

运行记录保存计划引用、稳定动作、尝试号与当前结果。完成标记仅在全部动作核验且通知清空后写入。后续保留策略可在同一状态锁下区分应保护的运行。
