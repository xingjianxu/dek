# #4 在 profile 注册中声明输入策略

状态为已采纳。

## 背景

清单用路径字符串注册公共 profile。后续缓存需要判断 Ruby profile 的作者是否承诺通过 SDK 读取可跟踪的输入。参见 [#4](../tasks/4.md) 和 [#18](../tasks/18.md)。

## 考虑的方案

- 统一改用对象。每个别名都有一致的结构，已有路径字符串需要迁移。
- 增加独立的输入策略表。已有注册保持简洁，一个 profile 的路径和输入策略分散在两个位置。
- 允许路径简写和对象。普通注册只需路径，需要声明策略的 profile 可在同一个条目中写出入口和策略。

## 决定与影响

清单 v1 接受路径简写和带 `entry`、可选 `inputs` 的对象。两种写法解析为统一的 profile 条目，路径简写采用默认输入策略。Ruby profile 用对象中的 `"inputs": "sdk"` 声明输入可跟踪，后续缓存据此判断该单元能否跨运行复用。
