# #20 离线读取 HTTP 输入并显式刷新

状态为已采纳，关联 [#20](../tasks/20.md)。

声明可以用 `http_text(url)` 在配置采集或模块展开时读取 HTTP 文本。若在普通规划时按需访问网络，重复规划会受到远端状态影响，离线运行也无法复用已有值。独立的刷新命令可以明确控制访问网络的时机。

响应保存在本地工作副本的缓存目录下，使用 `http/<prefix>/<url-sha256>.txt`。普通 `show` 和 `plan` 只读取已保存响应，缺少响应时提示 `dek refresh`。刷新沿选定主机的当前声明图和启用模块按实际调用访问 URL，同一次运行对同一 URL 只请求一次。选定主机之前读取的旧 URL 不参与本轮刷新，除非本轮再次访问该输入。

每个 URL 使用独立锁和同目录临时文件。客户端校验状态及完整 UTF-8 文本后原子替换响应，不跟随重定向。响应相同则保持已存文件。HTTP 失败、部分响应或无效文本会报告输入 URL 并保留上一份成功内容。声明和展开单元使用正文摘要判断各自是否需要重算。
