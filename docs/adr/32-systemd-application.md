# 系统级单元的定义、自启与运行状态

状态：接受（[#32](https://github.com/xingjianxu/dek/issues/32)）

系统级单元有三类状态。定义来自 `/etc/systemd/system` 中声明的主文件与 drop-in，自启与即时运行状态分别从目标 manager 查询。计划分别比较三类状态并冻结对应前置条件。撤销声明保留文件、自启与运行状态。

曾考虑让每次修改定义或自启时由 `systemctl` 隐式重载 manager。此行为会在同一批定义变化中反复重载。规划器将定义变化汇入一个系统级 `daemon-reload` 动作，并令同批系统级启停与通知等候该动作。自启动作使用 `--no-reload`。目标机执行时核验声明的定义内容及各项状态。

单个单元的待写文件全部通过内容校验后才依次原子替换。替换前再次检查审阅的定义状态，每个文件的发布还核对该文件的版本。运行记录在失败时保留可查询的动作结果。
