# #35 以受管块维护 SSH 授权公钥

状态：随 [#35](https://github.com/xingjianxu/dek/issues/35) 实施。

Linux 默认授权文件允许每把公钥携带登录限制。管理员和用户可能同时在文件中维护注释或手工规则。dek 在目标账户的 `~/.ssh/authorized_keys` 中使用一对标记，只替换标记内的条目。标记外的字节保持原样。显式空集合移除受管块，停止管理保留整个文件。标记损坏或同一公钥同时存在于手工条目和声明中时，报告冲突，防止以另一条授权绕过手工规则的限制。 [OpenSSH 授权文件格式](https://man.openbsd.org/sshd#AUTHORIZED_KEYS_FILE_FORMAT)

曾考虑通过单独的 `AuthorizedKeysFile` 路径隔离受管条目。该做法依赖修改 sshd 配置并重载服务，因此选择在默认文件内管理。计划从内容对象生成规范块并保存摘要。执行前重新确认目标账户、文件版本和已审阅内容，使用目录文件描述符拒绝符号链接，原子替换后独立复核。仓库文件随后变化时，指定原计划仍使用原审阅内容。
