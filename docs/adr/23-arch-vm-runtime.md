# #23 按轮隔离 Arch 测试来宾

状态为已采纳。

## 背景

同一 wks-lab 同时运行多个任务的集成验证。验证需要证明来宾重启后保留本轮变化，其他轮次和只读基盘均不受影响。仓库的首批验收可以在来宾无外网时运行。见 [任务 #23](../tasks/23.md)。

## 决定与影响

使用 QEMU/KVM 直接管理来宾，避免要求开发机另行配置 libvirt。每轮使用独立的 qcow2 差分盘和 UEFI 变量。QEMU 分配回环转发端口，管理脚本通过轮次私有的 QMP 套接字读取端口及检查实例归属。来宾重启沿用同一差分盘和预置主机密钥。收尾先请求来宾关机，超时后由 QMP 结束本实例。

由 NoCloud 从本轮只读 seed 获取账户和 SSH 密钥，客户端只信任该轮预置的主机公钥。默认禁用来宾外网访问。Arch 官方镜像在首次启动时等待网络时间同步，然后初始化 pacman 公钥环并开放 SSH。仅在测试来宾内屏蔽等待单元，让隔离环境也能完成 cloud-init。测试机器真实执行所部署的 `dek --version` 并核对摘要。
