# 远端显式输入的复核与快照

状态为已采纳，关联 [#41](https://github.com/xingjianxu/dek/issues/41)。

Ruby 的反向查询由管理端路由到已经核对身份的会话。事实、能力和文件使用同一个结构化查询操作。事实值来自目标标识，能力来自目标注册器。目标以会话账户的权限读取绝对路径上的 UTF-8 普通文件。文件缺失返回独立的观测状态，非法路径、读取错误和超过协议帧大小的内容返回带路径的诊断。普通 Ruby 文件读取继续发生在管理机上。

在握手中传全量输入会读取求值可能用不到的资料，目标文件的路径也只有执行声明后才知道。独立查询可以在语言调用与热缓存复核时复用，只有访问过的输入加入该单元的依赖。目标相关缓存键包含逻辑主机、传输别名与清单中的绑定标识。正式规划使用同一个已绑定的实时会话求值及请求计划，缓存热命中仍会向该会话复核观测。

管理端将目标响应按仓库、绑定和输入分别保存到原子替换的快照记录。逐项记录便于保留不同时间读取的输入，且更新其中一个文件时可复用其余输入的记录。记录包括值与观测摘要、缺失状态或目标返回的读取错误。连接错误保留已取得的记录。快照可能包含目标文件的原文，存放于管理机的求值缓存中，可随缓存一起删除。

`dek show --target-snapshot -H <host>` 显式使用该 SSH 绑定的本地快照。输出标明逻辑主机、SSH 别名和绑定的目标标识。未记录输入、缺少事实或读取失败时，诊断标明快照和 Ruby 请求来源。
