# #30 通过目标路径描述符管理目录

状态为已采纳。关联 [任务 #30](../tasks/30.md) 与[设计 §6.2](../design.md)。

目录后端直接管理目标文件系统。路径各级拒绝符号链接，审阅记录包括目录的设备号、inode 和声明的属主、属组及权限。用户和组由目标名称服务解析，同批声明的账户及祖先目录成为依赖；动作开始时读取账户已经分配的实际 ID。

新建目录在目标父目录内暂存，完成属性校验后原子发布。目的路径一旦被占用，发布失败。目录创建按系统 umask 从 0755 开始，显式 mode 暂存时设定。现存目录在已核对的描述符上设置属性，沿用省略的属性，保留目录 inode 与所有子项。缺失的祖先由其自身声明或管理员创建，解除故障后可根据当前状态重新应用。

直接操作使撤销声明立即结束管理。已有目录和文件继续使用当前权限，重启时没有 dek 生成的持久化 tmpfiles 规则。
