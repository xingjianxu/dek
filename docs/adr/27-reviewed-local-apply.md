# 审阅计划的执行复核

状态为已采纳，关联 [#27](https://github.com/xingjianxu/dek/issues/27)。

目标状态根内的独立执行锁覆盖复核、动作派发和核验。同一目标使用同一个可信状态根。`--state-dir` 可为独立目标环境配置私有状态根。运行记录和对象存储通过短状态事务读取、固定引用和提交回执，查询与保留检查可以在后端执行期间读取已固定的记录。

`apply --plan` 按仓库、逻辑主机及目标身份加载审阅内容，复核用过的能力和显式目标输入。执行器以冻结资源重新观察目标，只接受已审阅的类型化动作和依赖。原先已满足的资源出现新差异时保存并展示新计划，前置条件不符时保留当前目标状态。健康的审阅计划只使用目标内容存储中的字节，管理机源文件随后改动也不会改变这些字节。已变化的目标输入要求重新求值。

在动作启动前持久化尝试号和待核验状态。确认状态达标的幂等动作可记录零变更。结果不明的尝试先观察并核对，在原尝试号上记录已确认的结果。服务通知在依赖动作实际变更前登记，收到核验回执后解除待办。遇到动作错误或核验失败时保留回执并停止本次执行。

后端收到完整审阅动作、前置条件和经过摘要校验的内容。后端负责复核自身变更的前置条件、按动作所需权限操作和复读结果。首轮使用探针验证派发机制。各生产后端随相应任务提供执行能力。
