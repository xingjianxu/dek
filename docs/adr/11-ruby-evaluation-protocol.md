# #11 使用单行 JSON 在 Rust 与 Ruby 之间交换求值请求

状态：已采纳。

管理端需在一次运行中复用 Ruby 进程，并允许求值时按需查询目标。每单元启动 Ruby 会重复载入运行时。把 Ruby 嵌入 Rust 会增加运行时和发行依赖，也会把 Ruby 生命周期引入管理端进程。

采用设计 §3.1 的单行 JSON v1。父请求与反向查询各有 ID，每条信息带协议版本。每条求值请求构造新的请求上下文。协议独占原 stdout 管道，配置日志转到 stderr。在版本、解码、关联、脚本或目标查询失败时结束会话，调用方只在完整成功时收到输出和输入观测。

源码中的协议脚本在编译时嵌入二进制。安装后的管理端从 `PATH` 启动 Ruby，纯 JSON 的求值保持无需 Ruby 的部署方式。
