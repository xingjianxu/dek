# #12 记录 Ruby 声明实际消费的输入

状态为已采纳。

## 背景

入口可以直接读取配置文件内容，也可以单独声明待部署文件。缓存需要区分两类引用，并记录共享 Ruby 帮助文件及显式目标、HTTP 输入。参见 [#12](../tasks/12.md)、[#18](../tasks/18.md) 与 [#20](../tasks/20.md)。

## 决定

SDK 的读操作直接产生类型、标识、观测和调用位置。相对于统一在 Rust 猜测 Ruby 实际读取过的路径，直接记录可以区分条件分支、缺失输入和未使用的部署文件。入口与加载代码自动记录。复用已加载帮助文件时同时记录它的加载依赖，检测到源文件在求值中改变时终止采集。

本地文件和目录采用仓库内相对路径或仓库外绝对路径作为标识。环境变量名和 HTTP URL 使用调用时的文本。文件、环境和 HTTP 文本对读取的字节计算 SHA-256，目录对排序后的名称数组的紧凑 JSON 计算 SHA-256。目标观测由提供者返回。缺失本地读取显式记作 `Missing`，空文本按内容计算摘要。

`source_file` 对应 JSON 的相对路径字符串，规划阶段依据选项来源定位。Ruby 单元继续采用清单中的输入策略，声明 `inputs: "sdk"` 的作者承诺通过可观测接口读取影响结果的数据。
