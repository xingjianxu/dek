# 公钥文件与密文的读取时机

状态为已采纳。关联 [#10](https://github.com/xingjianxu/dek/issues/10) 和[设计 §6.3](../design.md#63-ssh-授权公钥与加密私钥)。

选项展开记录文件路径及生效来源，资源组装时再读取仓库公钥文件与 age 密文，并生成内容摘要和文件观测。同一份模块展开结果可在源文件修改后重新组装，保持声明采集与 Ruby 求值缓存可复用。若展开器直接读取文件，则每次内容变化都需产生新的展开结果并更新缓存依赖。

组装后的资源沿用核心类型，以摘要引用公钥文件与密文。管理端保留实际解析到仓库内的文件字节，identity 路径和输出路径随资源原样传给目标端。资源组装根据同批次已声明的账户、组和目录补充依赖。
