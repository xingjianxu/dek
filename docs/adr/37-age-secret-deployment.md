# #37 在目标端解密 age 文件并按明文差异通知服务

状态为已采纳。关联 [任务 #37](../tasks/37.md)、[验证标记 ADR](36-age-verification-markers.md) 和[设计 §6.3](../design.md)。

解密使用审阅过的密文字节和目标端预置的原生 X25519 identity，支持二进制及 ASCII armor 密文。identity 需要由执行账户持有，组和其他账户无访问位。路径解析拒绝符号链接并检查与解密 identity 的 inode 别名。身份文件调试信息、明文、明文指纹和解密库错误内容均不进入诊断与持久计划。

只有完整认证且不同的内容才暂存并原子替换目标。同一明文轮换收件人时更新验证标记，现存文件单独按需修正声明属性。受保护的目标状态在替换前登记 HMAC 检查点，发布并复读后替换验证标记。续办可通过匹配 HMAC 识别已发布的结果。持久记录不包含明文。

age 动作在已验证新内容确有变化且即将替换时登记后续服务通知。系统服务通过现有 `NotifyService` 执行，继续使用同一回执和续办路径。依赖通知前复核落点内容和元数据。`reloadUnits` 和 `restartUnits` 提供内置声明入口。
